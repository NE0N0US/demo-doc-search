# Тестовое задание «Страница документов»

## Установка зависимостей и запуск
```bash
npm i && npm start
```

## Сборка и предпросмотр
```bash
npm run build && npm run preview
```

## Описание
- Страница документов с поиском и предпросмотром по [макету](https://figma.com/file/xtAnJSWrI8khixoMeLzN3R/CISM-Frontend-Test-App-(Copy)?type=design&node-id=702-1284&mode=design&t=5LOrYhAKBEDt740D-0) с использованием [API](https://test-app-csm.up.railway.app/user/docs);
- Vue 3 Composition API, TypeScript, Pinia;
- Изоляция стилей компонентов, файлы Docker Compose и .env;
- Индикация загрузки, вывод ошибок, адаптивная вёрстка, автоматическая тёмная тема.
